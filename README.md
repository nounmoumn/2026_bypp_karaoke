# BYPP — Instant J-Pop Karaoke

**노래방에 없는 최애곡, 내가 읽을 수 있는 가사로 부르기.**

오디오와 일본어 가사에서 MR·한글 독음·동기화된 가사 화면을 만드는 개인용 웹 프로그램 기획이다. 자동 생성 후 틀린 독음·타이밍을 고쳐 완성하고, 키·음역 프리셋·Phone 출력·가사 모드를 바꿔 부른다. 실제 사용은 웹에서 반주를 스피커로 틀고 그 옆에 독립적인 노래방 마이크를 두는 방식이다. 마이크를 폰/PC에 연결하거나 브라우저 입력을 받지 않는다.

현재는 **T01 PoC 진행 중이며 만찬가 59초 구간 플레이어를 로컬에서 실행할 수 있다.** 분리·ASR·정렬·키 변환 실험 결과는 `docs/poc_results.md`에 기록했다. 플레이어는 수동 검수된 가사 시각과 생성된 MR을 사용한다. 새 곡 업로드·worker·자동 생성은 아직 구현되지 않았다.

1. [제품·기술 기획 v3](instant_jpop_karaoke_web_spec.md): 추가 요구를 통합한 범위·UX·데이터/API·완료 기준.
2. [구현 계획](docs/implementation_plan.md): 18시간 가정의 단계별 작업, 측정표, 검증, 후속 작업 지시.
3. [사용자 Final Spec](instant_jpop_karaoke_codex_final_spec.md): 키·프리셋·Phone Speaker 등 추가 요구의 원문과 통합 메모.
4. [수정 전 원본](docs/original_spec.md): 초기 아이디어 보존용. 현재 상세 구현 기준은 v3와 구현 계획이다.

로컬 실행은 [runbook](docs/runbook.md)을 따른다. 다음 단계는 다른 곡 두 구간의 T01 평가와 작업 API·worker 연결이다. 만찬가 한 곡의 자동 정렬은 시작·끝 정확도 목표에 미달했으므로, 현재 결과를 자동 생성 성공으로 표시하지 않는다.
